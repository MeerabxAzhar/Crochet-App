# Crochet Shopping App in Android Studio

This project is a mobile application developed in Android Studio using Java, designed for crochet enthusiasts to browse and purchase products online. The app showcases items like yarn, sweaters, socks, mufflers, and more, offering an intuitive and engaging shopping experience.

# Key Features:

- Product Listing: Browse crochet products with images, descriptions, and prices.
- Cart Management: Add or remove items, view products in the cart, and see total prices.
- Purchase Flow: Easy selection and management of products for checkout.
- Communication with Sellers: Users can send messages or emails directly to sellers regarding products or orders.
- Splash Screen: A polished splash screen enhances the app’s startup experience.
- User-Friendly Interface: Smooth navigation and interaction for a seamless shopping experience.

This app provides a complete mobile solution for crochet shopping, combining product browsing, cart management, price calculation, and direct communication with sellers in one platform. It ensures a modern and responsive experience for users looking to explore and buy crochet items.

# Pre-requirements:

- Android Studio IDE installed
- Java Development Kit (JDK 8 or higher)
- Android Emulator or physical device for testing
